## 🚀 GitHub ಗೆ ಅಪ್‌ಲೋಡ್ ಮಾಡುವುದು ಹೇಗೆ? (How to Upload to GitHub)

ಈ ಪ್ರಾಜೆಕ್ಟ್ ಅನ್ನು ನಿಮ್ಮ GitHub ಖಾತೆಗೆ ಅಪ್‌ಲೋಡ್ ಮಾಡಲು ಅತ್ಯಂತ ಸುಲಭ ವಿಧಾನ:

1. **GitHub ನಲ್ಲಿ ಹೊಸ Repository ರಚಿಸಿ**:
   - [github.com](https://github.com) ಗೆ ಹೋಗಿ ಲಾಗಿನ್ ಆಗಿ.
   - ಮೇಲ್ಭಾಗದಲ್ಲಿರುವ **"+"** ಐಕಾನ್ ಕ್ಲಿಕ್ ಮಾಡಿ &rarr; **"New repository"** ಆಯ್ಕೆಮಾಡಿ.
   - Repository name ನೀಡಿ (ಉದಾ: `exam-result-software`).
   - **Public** ಆಯ್ಕೆ ಮಾಡಿ **"Create repository"** ಕ್ಲಿಕ್ ಮಾಡಿ.

2. **ಫೈಲ್‌ಗಳನ್ನು ಅಪ್‌ಲೋಡ್ ಮಾಡಿ (Upload Files)**:
   - ರೆಪೊಸಿಟರಿ ಪುಟದಲ್ಲಿ **"uploading an existing file"** ಲಿಂಕ್ ಕ್ಲಿಕ್ ಮಾಡಿ.
   - ಈ ಫೋಲ್ಡರ್‌ನಲ್ಲಿರುವ ಫೈಲ್‌ಗಳನ್ನು ಡ್ರ್ಯಾಗ್ & ಡ್ರಾಪ್ ಮಾಡಿ:
     - `index.html` (ಸಂಪೂರ್ಣ ಸಿಂಗಲ್ ಫೈಲ್ ವೆಬ್ ಆ್ಯಪ್)
     - `google_apps_script.js` (ಗೂಗಲ್ ಶೀಟ್ ಬ್ಯಾಕೆಂಡ್ ಕೋಡ್)
     - `README.md` (ಕೈಪಿಡಿ)
   - ಕೆಳಗಿರುವ **"Commit changes"** ಕ್ಲಿಕ್ ಮಾಡಿ.

3. **ಉಚಿತ ಲೈವ್ ವೆಬ್‌ಸೈಟ್ ಆಕ್ಟಿವೇಟ್ ಮಾಡಿ (Enable GitHub Pages - Free Live URL)**:
   - ನಿಮ್ಮ GitHub repository ಯಲ್ಲಿ **Settings** ಟ್ಯಾಬ್‌ಗೆ ಹೋಗಿ.
   - ಎಡಭಾಗದ ಮೆನುವಿನಲ್ಲಿ **Pages** ಕ್ಲಿಕ್ ಮಾಡಿ.
   - **Branch** ಅಡಿಯಲ್ಲಿ `None` ಬದಲಿಗೆ **`main`** ಆಯ್ಕೆ ಮಾಡಿ &rarr; Folder: `/ (root)` ಇರಲಿ &rarr; **Save** ಕ್ಲಿಕ್ ಮಾಡಿ.
   - 1-2 ನಿಮಿಷಗಳಲ್ಲಿ ನಿಮ್ಮ ಲೈವ್ ವೆಬ್‌ಸೈಟ್ ಲಿಂಕ್ ಸಿದ್ಧವಾಗುತ್ತದೆ (ಉದಾ: `https://your-username.github.io/exam-result-software/`).
   - ಇದನ್ನು ನಿಮ್ಮ ಮೊಬೈಲ್ ಅಥವಾ ಯಾವುದೇ ಕಂಪ್ಯೂಟರ್‌ನಲ್ಲಿ ನೇರವಾಗಿ ಓಪನ್ ಮಾಡಿ ಬಳಸಬಹುದು!

## 🌟 ಪ್ರಮುಖ ವೈಶಿಷ್ಟ್ಯಗಳು (Key Features)

1. **ಏಕ ಫೈಲ್ ವಿನ್ಯಾಸ (Single Self-Contained File)**:
   - `index.html` ಒಂದೇ ಫೈಲ್‌ನಲ್ಲಿ ಸಂಪೂರ್ಣ ಅಪ್ಲಿಕೇಶನ್ ಅಡಕವಾಗಿದೆ.
   - ಆಫ್‌ಲೈನ್‌ನಲ್ಲೂ ನೇರವಾಗಿ ಡಬಲ್-ಕ್ಲಿಕ್ ಮಾಡಿ ಓಪನ್ ಮಾಡಬಹುದು.

2. **ಪರೀಕ್ಷೆ ಮತ್ತು ಆವೃತ್ತಿಗಳ ರಚನೆ (Versions A, B, C, D)**:
   - ಪರೀಕ್ಷೆಯ ಹೆಸರು ಮತ್ತು ಒಟ್ಟು ಪ್ರಶ್ನೆಗಳ ಸಂಖ್ಯೆ (1 ರಿಂದ 250).
   - ಪ್ರಶ್ನೆಗಳ ಸಂಖ್ಯೆಯನ್ನು ನಮೂದಿಸಿದ ತಕ್ಷಣ ಡೈನಾಮಿಕ್ ಆಗಿ ಗ್ರಿಡ್ ವಿಸ್ತರಿಸುತ್ತದೆ.
   - Quick Bulk Paste ಮೂಲಕ 100 ಕೀ ಉತ್ತರಗಳನ್ನು ಒಟ್ಟಿಗೆ ಪೇಸ್ಟ್ ಮಾಡಬಹುದು (`ABCD...`).

3. **ನೆಗೆಟಿವ್ ಮಾರ್ಕಿಂಗ್ (1/4th Negative Marking)**:
   - ಡೀಫಾಲ್ಟ್ 1/4th (-0.25 ಅಂಕ) ಅಥವಾ ಕಸ್ಟಮ್ ನೆಗೆಟಿವ್ ಕಡಿತ.
   - ಸೂತ್ರ:
     $$\text{ಅಂತಿಮ ಅಂಕಗಳು} = (\text{ಸರಿ} \times 1) - (\text{ತಪ್ಪು} \times 0.25)$$

4. **ಅಭ್ಯರ್ಥಿಗಳ OMR ಎಂಟ್ರಿ & Excel/CSV ಅಪ್‌ಲೋಡ್**:
   - ಒಂದೊಂದಾಗಿ OMR ಬಬಲ್ಸ್ ಮೂಲಕ ಅಥವಾ Excel/CSV ಫೈಲ್ ಅಪ್‌ಲೋಡ್ ಮಾಡಿ ನೂರಾರು ಅಭ್ಯರ್ಥಿಗಳ ಡೇಟಾ ಆಮದು.

5. **ಮೆರಿಟ್ ಲಿಸ್ಟ್ & ರಾಂಕಿಂಗ್ (Leaderboard)**:
   - Rank 1, 2, 3 ಬ್ಯಾಡ್ಜ್‌ಗಳು, ಸರಿ, ತಪ್ಪು, ನೆಗೆಟಿವ್ ಕಡಿತ ಮತ್ತು ಅಂತಿಮ ಅಂಕಗಳು.
   - Excel ಡೌನ್‌ಲೋಡ್ & ಪ್ರಿಂಟ್ ಸೌಲಭ್ಯ.

6. **ವೈಯಕ್ತಿಕ ಸ್ಕೋರ್‌ಕಾರ್ಡ್ (Candidate Scorecard)**:
   - ಪ್ರತಿ ವಿದ್ಯಾರ್ಥಿಗೂ ಪ್ರತ್ಯೇಕ A4 ಪ್ರಿಂಟೇಬಲ್ ಅಂಕಪಟ್ಟಿ ಹಾಗೂ ಪ್ರಶ್ನೆವಾರು ಸಮಗ್ರ ವಿಶ್ಲೇಷಣೆ.

7. **ಗೂಗಲ್ ಶೀಟ್ & Apps Script ನೇರ ಆಮದು & 2-ವೇ ಸಿಂಕ್ (Dual Cloud Engine)**:
   - **Google Apps Script Web App URL**:
     `https://script.google.com/macros/s/AKfycbx81T4anZcoYRQjMkSOSgtwGOeyWcY0PC2gFGovCIBna1hTRrlYZcQ30W2N25YNxQLl7Q/exec`
   - **Google Spreadsheet URL**:
     `https://docs.google.com/spreadsheets/d/1-NAZdSlS8QKTGFMPLwmHfToy07Jh2H5cfewgx7u3CDw/edit`
   - **1-ಕ್ಲಿಕ್ ಡೇಟಾ ಪಡೆಯಿರಿ**: ಅಪ್ಲಿಕೇಶನ್‌ನಲ್ಲಿ **"ಶೀಟ್ ಡೇಟಾ ಪಡೆಯಿರಿ (Fetch Sheet)"** ಬಟನ್ ಕ್ಲಿಕ್ ಮಾಡಿದ ತಕ್ಷಣ Apps Script API ಮೂಲಕ ಎಲ್ಲಾ ಪರೀಕ್ಷೆಗಳು, ಕೀ-ಉತ್ತರಗಳು ಹಾಗೂ ಅಭ್ಯರ್ಥಿಗಳ OMR ಡೇಟಾ ತಕ್ಷಣವೇ ಲೋಡ್ ಆಗುತ್ತದೆ.
   - **ಸ್ವಯಂ-ಪತ್ತೆ (Auto Detection)**:
     - ಪರೀಕ್ಷೆಗಳು, ಸೆಟ್‌ಗಳು (`A1`, `B1`, `C1`, `D1`), ಕೀ-ಉತ್ತರಗಳು ಮತ್ತು ಅಭ್ಯರ್ಥಿಗಳನ್ನು ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಮ್ಯಾಪ್ ಮಾಡುತ್ತದೆ.
     - `1, 2, 3, 4` ಆಯ್ಕೆಗಳನ್ನು `A, B, C, D` ಗೆ ಮತ್ತು ಖಾಲಿ ಇದ್ದರೆ Not Response (NR) ಗೆ ಮ್ಯಾಪ್ ಮಾಡುತ್ತದೆ.
   - **2-ವೇ ಸಿಂಕ್ (Two-Way Sync)**:
     - **Pull/Fetch**: ಗೂಗಲ್ ಶೀಟ್/Apps Script ನಿಂದ ಪರೀಕ್ಷೆ ಮತ್ತು OMR ಡೇಟಾ ಡೌನ್‌ಲೋಡ್.
     - **Push/Sync**: ಲೆಕ್ಕಹಾಕಿದ ಮೆರಿಟ್ ಪಟ್ಟಿ, ರಾಂಕಿಂಗ್ ಮತ್ತು ಅಂಕಗಳನ್ನು ನೇರವಾಗಿ ಗೂಗಲ್ ಶೀಟ್‌ಗೆ ಸೇವ್ ಮಾಡುವುದು.
