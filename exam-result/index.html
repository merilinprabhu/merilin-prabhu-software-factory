ಅಂತಿಮ ಮೆರಿಟ್ ಪಟ್ಟಿ

ರಾಂಕ್ ರೋಲ್ ನಂ ಅಭ್ಯರ್ಥಿಯ ಹೆಸರು ಆವೃತ್ತಿ ಪ್ರಯತ್ನಿಸಿದ್ದು ಸರಿ (Correct) ತಪ್ಪು (Wrong) ಖಾಲಿ (Blank) ನೆಗೆಟಿವ್ ಕಡಿತ ಅಂತಿಮ ಅಂಕ ಶೇಕಡಾವಾರು (%) ವಿವರಣೆ
ಫಲಿತಾಂಶ ಸಿದ್ಧಪಡಿಸಲು ಅಭ್ಯರ್ಥಿಗಳನ್ನು ಮತ್ತು ಕೀ ಉತ್ತರಗಳನ್ನು ದಾಖಲಿಸಿ.

ಅಭ್ಯರ್ಥಿಯ ವಿವರವಾದ ಸ್ಕೋರ್‌ಕಾರ್ಡ್ (Candidate Scorecard)

ಅಭ್ಯರ್ಥಿಯ ಹೆಸರನ್ನು ಆರಿಸಿ ಅವರ ಪ್ರಶ್ನೆವಾರು ಮೌಲ್ಯಮಾಪನ ನೋಡಿ ಮತ್ತು ಪ್ರಿಂಟ್ ಮಾಡಿ.

ದಯವಿಟ್ಟು ಸ್ಕೋರ್‌ಕಾರ್ಡ್ ನೋಡಲು ಮೇಲಿನಿಂದ ಅಭ್ಯರ್ಥಿಯನ್ನು ಆಯ್ಕೆಮಾಡಿ.

ಗೂಗಲ್ ಶೀಟ್ ಬ್ಯಾಕೆಂಡ್ ಸಂಪರ್ಕ (Google Sheets Integration)

ನಿಮ್ಮ ಗೂಗಲ್ ಶೀಟ್‌ನೊಂದಿಗೆ ಡೇಟಾವನ್ನು ಆಟೋಮ್ಯಾಟಿಕ್ ಆಗಿ ಸಿಂಕ್ ಮಾಡಿ ಶಾಶ್ವತವಾಗಿ ಕ್ಲೌಡ್‌ನಲ್ಲಿ ಶೇಖರಿಸಿ.

ಗೂಗಲ್ ಶೀಟ್ ವಿವರಗಳು (Sheet Details)

ಬಲಗಡೆ ನೀಡಿರುವ ಹಂತಗಳನ್ನು ಅನುಸರಿಸಿ ಪಡೆದ ವೆಬ್ ಆ್ಯಪ್ ಲಿಂಕ್ ಅನ್ನು ಇಲ್ಲಿ ಹಾಕಿ.

ಗೂಗಲ್ ಶೀಟ್ Web App URL ಪಡೆಯುವುದು ಹೇಗೆ? (ಸುಲಭ 5 ಹಂತಗಳು)

  1. ನಿಮ್ಮ ಗೂಗಲ್ ಶೀಟ್ ತೆರೆಯಿರಿ.
  2. ಮೇಲಿನ ಮೆನುವಿನಲ್ಲಿ Extensions (ವಿಸ್ತರಣೆಗಳು) → Apps Script ಕ್ಲಿಕ್ ಮಾಡಿ.
  3. ಅಲ್ಲಿ ಕಾಣಿಸುವ ಕೋಡ್ ತೆಗೆದು, ಈ ಪ್ರಾಜೆಕ್ಟ್‌ನಲ್ಲಿರುವ google_apps_script.js ಫೈಲ್‌ನ ಸಂಪೂರ್ಣ ಕೋಡ್ ಅನ್ನು ಕಾಪಿ ಮಾಡಿ ಪೇಸ್ಟ್ ಮಾಡಿ ಮತ್ತು Save (Ctrl+S) ಮಾಡಿ.
  4. ಮೇಲಿನ Deploy ಬಟನ್ ಕ್ಲಿಕ್ ಮಾಡಿ → New deployment ಆಯ್ಕೆ ಮಾಡಿ:
    • Select type: Web app
    • Execute as: Me
    • Who has access: Anyone (ಯಾರಾದರೂ)
  5. Deploy ಕ್ಲಿಕ್ ಮಾಡಿ, ಅಲ್ಲಿ ಬರುವ Web app URL ಅನ್ನು ಕಾಪಿ ಮಾಡಿ ಎಡಭಾಗದಲ್ಲಿರುವ ಬಾಕ್ಸ್‌ನಲ್ಲಿ ಪೇಸ್ಟ್ ಮಾಡಿ "URL ಉಳಿಸಿ" ಕ್ಲಿಕ್ ಮಾಡಿ!

ಗಮನಿಸಿ: ನೀವು ಸದ್ಯಕ್ಕೆ ಗೂಗಲ್ ಶೀಟ್ ಲಿಂಕ್ ಮಾಡದಿದ್ದರೂ ಸಹ ಸಾಫ್ಟ್‌ವೇರ್ ಸಂಪೂರ್ಣವಾಗಿ ನಿಮ್ಮ ಕಂಪ್ಯೂಟರ್‌ನ ಬ್ರೌಸರ್‌ನಲ್ಲಿಯೇ (Local Storage) ಯಾವುದೇ ಅಡೆತಡೆಯಿಲ್ಲದೆ ರನ್ ಆಗುತ್ತದೆ!

ಕೀ ಉತ್ತರಗಳನ್ನು ಒಟ್ಟಿಗೆ ಪೇಸ್ಟ್ ಮಾಡಿ (Bulk Key Paste)
